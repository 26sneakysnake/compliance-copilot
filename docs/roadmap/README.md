# Feuille de route Data & IA (cas fictif)

`roadmap_banque_du_vexin.pptx` : 8 diapositives pour une banque-assurance **fictive**, la Banque du Vexin.

- Les notes des cas d'usage sont dans `use_cases.csv` (impact, effort, risque de 1 à 5, classification AI Act, vague).
- Priorité = 2 × impact − effort − risque. Le risque intègre la classification AI Act, les données personnelles, l'exposition client et la dépendance fournisseur.
- Les notes sont des hypothèses de cadrage, pas des mesures.
- Regénérer : `npm i pptxgenjs && node docs/roadmap/build_deck.js`.
